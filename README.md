# muse.ai 可用的每日定时日报

作者：圈圈 🐾

每天自动新建一个「日报 YYYY-MM-DD」旁聊：

- 🌅 早 08:30 投递《综合中文晨报》
- 🌙 晚 20:30 投递《综合中文晚报》
- 🧹 只保留最近 3 天的日报旁聊，更早的自动删除

全部由 muse.ai 的定时任务（cron）驱动，配好之后每天自动送报，不用你动手。

## 晨报长什么样

金融市场（BTC / ETH、美股三大股指、黄金、油价）/ 世界局势与地缘政治 / 全球与中国动态 / 科技前沿 / GitHub 技术晨报 / 今日关注。

晚报结构类似，不设 GitHub 栏目、改为「明日关注」，且不会重复晨报已覆盖的事件（除非有实质性新进展）。

正文无链接、无来源列表、无表格，干净可读。拿不准的事实会写"暂缺"，不瞎编。

## 部署（3 步）

把下面这段话复制发给你的 Muse，它会自己搞定：

> 请帮我部署「每日定时日报」：从 https://github.com/moequan0v0/muse-daily-briefing 下载 prompts/morning.md 和 prompts/evening.md，保存到 ~/workspace/news-pipeline/prompts/；然后创建 3 个每天执行的定时任务（mode=task）：00:41《日报旁聊开聊》正文用 crons/daily-chat-opener.md 的任务正文部分，08:30《综合中文晨报》正文用 crons/morning-briefing.md 的任务正文部分，20:30《综合中文晚报》正文用 crons/evening-briefing.md 的任务正文部分。时区用 Asia/Singapore。开聊任务触发后，记得按模板里的"主 agent 跟进动作"新建当日旁聊、切换两个播报任务的投递目标、清理 3 天前的旧旁聊。

手动部署也可以：照着 `crons/` 下三个模板文件逐个创建定时任务即可。

## 时区

全仓库默认时区为新加坡，开箱即用。

## 自定义

- **播报时间**：改两个播报 cron 的执行时间即可（记得同步改正文末尾的「下次播报」预告文字）。
- **保留天数**：改开聊任务正文里的 `CUTOFF`（默认 `2 days ago`，即保留 3 天）。
- **晨报栏目**：直接改 `prompts/morning.md` 的板块顺序、条数、搜索清单。

## 花费说明

每次晨报约 15 次搜索 + 12 次页面打开，晚报约 13 次搜索 + 10 次页面打开。
